# Value Proposition

This document captures the core value of the GloBE Model in concise, memorable English sentences that can be reused in client conversations, demonstrations, and marketing materials.

## Core Value

- The GloBE Model translates complex Pillar Two rules into a structured and executable calculation model.
- It is designed to make the logic behind Pillar Two calculations transparent, explainable, and reproducible.
- The model bridges tax interpretation, mathematical modeling, data structure, and software implementation in a single framework.
- Instead of treating Pillar Two as a collection of isolated spreadsheet calculations, the model represents the rules as a coherent system of entities, relationships, and calculation logic.
- The model is built to separate regulatory logic from client-specific data and implementation details, making the core methodology reusable across different MNE groups.
- Complex ownership, control, JV, investment entity, IIR, UTPR, and safe harbour rules can be expressed consistently within the same modeling framework.
- The model is designed not only to calculate an answer, but also to explain how that answer was derived.
- A formalized model makes it easier to test edge cases, identify inconsistencies, and update the calculation when regulations change.

## Why It Matters

- Pillar Two is difficult not because any single formula is impossible, but because many interdependent rules must work correctly together.
- The GloBE Model reduces that complexity by turning regulatory interpretation into explicit relationships and calculation logic.
- This creates a foundation for automation without sacrificing tax technical rigor.
- It also reduces dependence on opaque, manually maintained spreadsheet logic.

## Positioning

- This is not simply a tax calculator. It is a formal model of how the Pillar Two rules operate.
- The objective is to make Pillar Two calculations auditable, maintainable, and scalable.
- The value of the model lies in combining deep tax domain knowledge with rigorous modeling and practical implementation.

## Short Marketing Lines

- We do not just calculate Pillar Two. We model how Pillar Two works.
- The model turns regulatory complexity into transparent and executable logic.
- Every number should be traceable back to the rule that created it.
- Complex tax rules become manageable when their relationships are modeled explicitly.
- Automation is valuable only when the underlying tax logic is correct and explainable.
- The GloBE Model is designed to preserve both technical rigor and implementation flexibility.
